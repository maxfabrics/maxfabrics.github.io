Copyglow

Copier un code Wi-Fi ou de carte cadeau sans le recopier à la main

Vingt caractères à recopier depuis une étiquette de box ou une carte à gratter, et une erreur sur deux. Il y a plus simple.

Quand il y a un QR code

Beaucoup de box récentes impriment un QR code Wi-Fi : l'appareil photo d'Android le lit et propose de se connecter. Pour partager ton propre Wi-Fi, la plupart des téléphones Android récents affichent un QR code dans les réglages du réseau (bouton « Partager »).

Quand il n'y a que du texte

Étiquette de box sans QR, carte cadeau à gratter, clé de licence sur une boîte : la reconnaissance de texte d'une photo copie souvent tout le bloc, et il faut ensuite isoler le bon code. Prends la photo bien à plat, nette, sans reflet, et vérifie le résultat avant de coller.

Les confusions classiques

  • 0 et O, 1, I et l, 5 et S, 8 et B : vérifie ces caractères un par un.
  • Les tirets entre les groupes : certains formulaires les veulent, d'autres non.
  • Un IBAN a une clé de contrôle : une seule erreur de chiffre la rend fausse.

Attention aux arnaques aux cartes cadeaux

Personne de sérieux (impôts, banque, support technique, livreur) ne demande d'être payé en codes de cartes cadeaux. Si on te réclame un code par téléphone ou par message, c'est une arnaque : ne le donne jamais.

Le faire avec Copyglow

Copyglow trouve le code dans la photo et le copie aussitôt : mot de passe Wi-Fi, carte cadeau, clé de licence, code promo, IBAN avec sa clé vérifiée, QR codes. Il laisse de côté les dates, les prix et les numéros de téléphone, signale les caractères faciles à confondre, et la lecture se fait sur ton téléphone, sans compte. Toutes les fonctions sont gratuites.

Questions fréquentes

Comment copier un mot de passe Wi-Fi depuis l'étiquette de ma box ?

S'il y a un QR code, l'appareil photo d'Android le lit. Sinon, prends l'étiquette en photo : Copyglow trouve le mot de passe dans l'image et le copie.

Comment éviter de confondre 0 et O dans un code ?

Vérifie ces caractères un par un. Copyglow les signale et passe à l'autre lecture d'un toucher.

Peut-on payer une facture avec une carte cadeau ?

Non. Un organisme qui réclame un paiement en code de carte cadeau est une arnaque.
